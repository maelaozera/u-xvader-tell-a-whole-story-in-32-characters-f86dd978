## The entry

**SheSaidYes,ThenChangedTheWiFi** (29 characters)

The story in one breath: he proposed, she said yes — then she changed the Wi-Fi. The network name a stranger is staring at in their phone's network list *is* the network she changed: the proposal, the twist, and the break-up ending, with the Wi-Fi itself as the plot device. No stock joke, no explanation needed.

## How to run

Requires Node 22 or later (no dependencies):

```sh
node main.ts
```

It writes the Wi-Fi name to `/output/entry.txt`, after a self-check that the entry is 1–32 characters, not only white space, and a single line.
